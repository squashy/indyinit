# 006: Where people stay in the loop

## Current Indiana demo precedence

`CONTRACT.md` and later explicit owner decisions control this demo. Conflicting instructions below are historical, not current release gates. The quiz bonus is fixed at +2 once per turn. Use the supplied repository CSV; do not generate replacement trivia. Factual QA, both-checker verdicts, ledger merge and random factual audits are deferred, not completed. Legacy content quotas do not block this CSV import. Structural mapping and security checks remain required. Hidden benchmark truth labels remain private; supplied gameplay correct letters and answers ship. No hosted CI or previews. Changes use branches and PRs with non-author exact-head approval, local box checks and main-only production deployment. The UI must say "Questions unverified" and must not claim the demo is fact-checked.

**Status:** Accepted for human merge. Factual audits, disagreement rulings, and key holding in the decision below are deferred for the current Indiana demo, not Done.

**Decision:** Agents write code, open pull requests, and take tickets. An authorized person merges after non-author exact-head approval. Production deploys only from `main`. People still change bars and hold the hidden benchmark key away from agents. Ruling fact disagreements and auditing 15 random questions per state are historical duties. They are not current import or release gates.

**Why:** Autonomy goes where mistakes are cheap and tests catch them. Merging keeps one human decision between an agent and a child, without adding a release step to an eight-hour day.

**Hard history:** Questions on topics like slavery, the removal of Native peoples, lynching or the Klan follow the same process as any question. The writing brief requires honest, age-appropriate language, but we add no separate review, which keeps the pipeline uniform and fast. The risk is that wording suited to neither a child nor a teacher could ship. A real classroom release would add a dedicated review first.

**Tradeoffs:** Most questions will not be read by a person. We state that plainly to judges.
